Métodos de Tiragem

As tiragens apresentadas aqui não têm foco adivinhatório. O objetivo é utilizar as imagens arquetípicas das cartas como espelhos para processos psíquicos internos, facilitando a reflexão e a individuação.

Método da Tiragem Simples

Este método consiste em sortear uma carta para obter insights sobre uma situação específica.

A Tríade Psíquica (3 Cartas)

Ideal para momentos de confusão mental ou quando há um conflito interno aparente. Esta leitura adapta o método tradicional de "Passado, Presente e Futuro" para a estrutura analítica.

  • Carta 1 (A Sombra): O que está oculto no inconsciente, medos reprimidos ou potenciais ignorados relacionados à situação.
  • Carta 2 (O Ego): Como você está lidando conscientemente com o problema neste momento.
  • Carta 3 (O Self): O caminho de integração, o conselho do seu eu mais profundo para alcançar o equilíbrio.

O Mandala Psíquica (9 Cartas)

Este método é mais complexo e permite uma análise profunda da psique, explorando múltiplos aspectos de uma situação ou de si mesmo.

  • Carta 1: O que está consciente.
  • Carta 2: O que está inconsciente.
  • Carta 3: O que está reprimido.
  • Carta 4: O que é projetado nos outros.
  • Carta 5: O que é negado.
  • Carta 6: O que é idealizado.
  • Carta 7: O que é desejado.
  • Carta 8: O que é temido.
  • Carta 9: A síntese, o conselho do Self para a integração dos aspectos revelados.
