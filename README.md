# O Diário Místico

Projeto acadêmico desenvolvido para a avaliação da disciplina de Introdução ao Desenvolvimento Web.

## Sobre o Projeto
Um site estruturado exclusivamente em HTML5 focado na integração dos arquétipos do Tarot com a Psicologia Analítica, utilizando a obra de Sallie Nichols como referência para o processo de individuação.

## Requisitos Técnicos Aplicados
- Estrutura semântica HTML5 completa
- Formulário com validação nativa
- Incorporação de mídias e tabelas acessíveis
